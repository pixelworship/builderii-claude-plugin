# Summarize a Builderii board

1. **Find it.** `search` or `list_boards` with a word from the name the user gave. If several match, ask which one.
2. **Read it** with `read_board` (or `fetch`). To leave the summary on the board as a note, or for a long board, `summarize_board` has Builderii's AI write it.
3. **Answer what was asked.** For a summary: what the board is for, its pages, then per page the flow (start screen or first step, the main path and the branches), the main ideas, and open comments with who wrote them. For a question: answer it from the outline, quoting the screen, step or note names.
4. **Stay with the board.** Say so when the board doesn't answer the question, instead of guessing.
5. **Link it.** End with the board's link.
